# UnrealDevFlow v0.1.0

## 一句话总结

首个可安装版本，把 UE 插件的 AI 并行开发流程产品化：任务隔离、编译验证、插件切换、安全合并和清理都由 CLI 统一管理。

## 安装 / 升级

```powershell
__INSTALL_COMMAND__
```

## 重点变化

- 从手动维护 Git worktree、Host 项目和 NTFS Junction，升级为一套固定命令流。
- 面向 UE 插件依赖建模：主插件用独立 worktree 开发，依赖插件用只读 Junction 参与编译。
- 面向 AI agent 加约束：任务保存原始 prompt，agent skill 明确禁止直接改主仓库和裸跑危险 git 合并。
- 发布方式从“源码构建”变为 Windows 预编译包 + installer + checksum。

## 新增

- 新增 `configure/create/build/build-status/switch/list/status/merge/cleanup/delete` 等核心命令，覆盖任务从创建到清理的完整生命周期。
- 新增 Host 项目生成能力：每个任务拥有独立 Host `.uproject`、插件目录和编译日志。
- 新增 v2 多插件模型：支持多个 primary 插件，自动扫描 `.uplugin` 依赖，区分 engine/project/custom dependency。
- 新增严格 UBT 编译参数、build profile、mutex 三态和后台编译能力。
- 新增 merge 策略参数：`rebase/merge/squash/ff-only`，并在 merge 前展示分支分叉信息。
- 新增跨 agent skill 安装入口，覆盖 Codex、Claude Code、Copilot/opencode 相关入口文档。
- 新增 Windows Release 打包流程：exe、zip、installer、checksum、release notes 统一产出。

## 修复

- 修复 create/switch/delete 测试中发现的基础路径和 worktree 清理问题。
- 修复 delete/merge 前未 `git worktree prune` 导致的残留 worktree 注册问题。
- 修复 worktree 目录已被手动删除时 cleanup/delete 无法继续恢复的问题。
- 修复 switch 冲突检测和断开的 Junction 自动清理问题。
- 修复 build 命令 UBT 严格参数、regen 锁和 `-NoLog` 相关问题。
- 修复 merge 命令误承担删除职责的问题：merge 只合并，清理必须走 cleanup。

## 破坏性变更

- 无旧 release 升级破坏；这是首个公开安装版本。
- 使用 merge 时必须显式选择 `--strategy`，这是为了让 agent 不再默认猜合并方式。

## AI Agent 变化

- 发布 `unrealdevflow` skill，要求 agent 只在任务 worktree 中工作，不直接修改主仓库。
- `create --prompt` 会保存用户原始需求，后续 agent 可以从任务元信息恢复上下文。
- 文档中明确：switch 需要用户验收配合，merge 后不能自动 cleanup。
- commit message 规范加入中文“修改内容 / 过程反思 / 后续注意”，用于沉淀任务教训。

## 校验

- GitHub Actions release workflow 成功生成 Windows 资产。
- `scripts/release-preflight.ps1 -Strict`
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`
- `cargo test --workspace --all-targets --all-features --locked`
- `cargo build --release --locked`
- `target/release/unrealdevflow.exe --version`
