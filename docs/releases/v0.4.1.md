# UnrealDevFlow v0.4.1

## 一句话总结

修复 Windows PowerShell 5.1 下默认的一行安装命令，确保 GitHub Release 安装脚本在交给 `iex` 前被完整聚合。

## 安装 / 升级

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/pb763396199/UnrealDevFlow/releases/latest/download/unrealdevflow-installer.ps1 | Out-String | iex"
```

## 重点变化

- Windows PowerShell 5.1 的默认安装入口现在会先聚合完整响应，再交给 `iex`。
- 所有公开安装说明和自动生成的 Release Notes 使用同一条可靠命令。

## 新增

- 发布预检新增安装命令一致性门禁。

## 修复

- 修复 `Invoke-RestMethod` 在 Windows PowerShell 5.1 下可能逐行枚举 `.ps1` 响应，导致多行注释或语句被拆开并触发解析错误的问题。
- README、发布规范、Agent Skill 和发布说明生成器统一使用同一条安装命令。
- 发布预检新增静态门禁，防止任何公开安装入口遗漏 `Out-String` 聚合步骤。

## 兼容性

无破坏性变更。Package、Build、Task、Workspace 和 Skill 命令行为与 v0.4.0 相同。

## 破坏性变更

无。

## AI Agent 变化

- Agent 安装或升级 UnrealDevFlow 时应使用带 `Out-String` 的公开命令。

## 校验

- Windows PowerShell 5.1 从 GitHub `latest` URL 下载并执行安装器。
- 全局命令解析到 `%USERPROFILE%\.unrealdevflow\bin\udf.exe`。
- `udf --version` 输出 `0.4.1`。

## 变更列表

由发布脚本根据 `v0.4.0..v0.4.1` 自动生成。
