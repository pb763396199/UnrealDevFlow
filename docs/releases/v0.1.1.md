# UnrealDevFlow v0.1.1

## 一句话总结

安装器热修版，重点修正安装后命令解析路径，确保普通用户执行的就是刚安装的 release 版本。

## 安装 / 升级

```powershell
__INSTALL_COMMAND__
```

## 重点变化

- 安装器不再只检查“能运行 unrealdevflow”，而是检查 `Get-Command unrealdevflow` 是否指向 `%USERPROFILE%\.unrealdevflow\bin\unrealdevflow.exe`。
- 安装目录会被移动到 User PATH 和当前 PowerShell 会话 PATH 的最前面，避免被源码目录或旧二进制抢先命中。
- AI skill 安装改为优先使用 exe 旁边随 release 打包的 skill，而不是误读开发仓库中的副本。

## 新增

- 安装器增加 PATH 解析源校验，失败时直接报错，避免用户以为升级成功但实际仍在跑旧版本。

## 修复

- 修复在源码仓库内执行 installer 时，PATH 可能解析到 `target/release/unrealdevflow.exe` 或旧位置的问题。
- 修复 `skills install` 对源码目录的隐式依赖，让安装后的独立 release 包也能安装全局 AI skill。
- 修复安装后当前终端 PATH 顺序不稳定的问题。

## 破坏性变更

- 无。

## AI Agent 变化

- agent 安装到全局的 `unrealdevflow` skill 现在来自 release 包内置版本，降低“源码副本和已安装版本不一致”的风险。
- installer smoke test 的验收口径升级为“命令来源正确 + 版本正确”，不是只看命令能启动。

## 校验

- GitHub Actions release workflow 成功。
- latest/download 安装入口发布后通过 smoke test。
- `scripts/release-preflight.ps1 -Strict`
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`
- `cargo test --workspace --all-targets --all-features --locked`
- `cargo build --release --locked`
- `target/release/unrealdevflow.exe --version`
